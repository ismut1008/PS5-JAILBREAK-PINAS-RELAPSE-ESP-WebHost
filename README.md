# PS5-JAILBREAK-PINAS-RELAPSE-ESP-WebHost
ESP32S2 Chip Webhost base on Karo's version of Relapse for FW7.00 to FW13.60 with UNLI PAYLOADS ability where users can add Payloads on PS5's INTERNAL STORAGE and will auto populate on the webhost itself, without rebooting.

What if offers?
--------------------

- Pure offline webhost solution for RELAPSE Jailbreak
- MEDIA TAB "shortcut icon" for quick navigation of the page
- COMES WITH 4 PAYLOADS ONLY (3MB limited space of the chip)
  - kstuff1.13drtest5.elf (so you can install apps you needed initially)
  - Browser_appCache_remove.elf (so you can remove previous cache)
  - nanodns0.4.elf 
  - web-file-mgr-v1.9.elf (so you can copy payloads you needed on your esp webhost)
- UNLI PAYLOADS feature (add Payloads on PS5's INTERNAL STORAGE and will auto populate on the webhost itself, without rebooting)
- base on Karo's Relapse Webhost with Stability Fix

UNLI PAYLOADS FEATURE
--------------------

- UNLIMITED PAYLOADS (users can add payloads on console's internal storage and will auto populate on the webhost itself, without rebooting)
    - click web file manager payload then run the app(media tab located), copy the payloads you want on the designated path (you can add and delete payloads that you want, except the pre-embedded payloads)
          
    - payload path:
    /user/home/(user-id)/webkit/shell/esp-payloads

    - payload path example:
    /user/home/(user-id)/webkit/shell/esp-payloads/onionhen.elf

Quick Q and A
--------------------------------------------

- Q: Why does Relapse "does not support offline caching"?
- A: Relapse has an "klsr" issue, where the exploit would not run without an active network connection (with or without internet will do, just like VUEJB on PS4... we don't know if this can be resolve in the future)
